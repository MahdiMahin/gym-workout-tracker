# Contributing

- Create branches named `feature/…`, `fix/…`, or `devops/…`.
- Use conventional commit prefixes: `feat:`, `fix:`, `ci:`, `chore:`, or `docs:`.
- Open a pull request for all changes; CI must pass before merging.
- Pull requests are squash-merged.
- For database changes, follow the [Supabase migration guide](supabase/README.md).
- Commit `frontend/package-lock.json` whenever frontend dependencies change.
